WHITE SHORE HOMESTAY - website

index.html          the page
css/style.css       all styling (colours are variables at the top)
js/main.js          editable settings: phone, address, photos, reviews, Instagram
images/             put property photos here (intro, rooms, gallery)
images/destinations Pondicherry attraction photos

To change a photo: replace the file with one of the same name, or edit its path in js/main.js.
To upload: copy the whole folder to Netlify / Cloudflare Pages / GitHub Pages (index.html must stay at the top level).
Open index.html directly in a browser to preview.
